# FitConnect AI Memory Bootstrap

**Status:** ENFORCED companion to `.ai.constitution.md`
**Goal:** reproducible engineering context with automatic drift detection.

Every AI/developer session that changes FitConnect MUST read, in order:

1. `.ai.constitution.md`
2. `.ai.memory.md`
3. `docs/ai-library/MEMORY_PROTOCOL.md`
4. `docs/ai-library/CURRENT_STATE.md`
5. `docs/ai-library/ARCHITECTURE_INDEX.md`
6. `docs/ai-library/OWNERSHIP_REGISTRY.md`
7. `docs/ai-library/SECURITY_BASELINE.md`
8. `docs/ai-library/DECISION_LOG.md`
9. `docs/ai-library/RELEASE_LEDGER.md`
10. relevant domain file(s) under `docs/ai-library/domains/`
11. relevant incident records under `docs/ai-library/incidents/`
12. current Git + Supabase/deployment state before mutation

## Memory hierarchy

- Constitution = immutable project law unless explicitly governed change.
- HOT memory (`CURRENT_STATE`) = resumable present state.
- WARM memory (architecture/ownership/security/domains/decisions) = stable contracts and rationale.
- COLD memory (release ledger/incidents) = append-only historical evidence.
- Git = code/migration/deployment intent truth.
- Supabase/deployed environment = runtime/data truth.
- Conversation context = temporary working memory only.

## Required session cycle

`READ -> AUDIT -> CLASSIFY -> REPAIR -> TEST -> VERIFY -> DOCUMENT -> GUARD -> GREEN`

A material change is not complete until durable memory is updated when it changes architecture, ownership, security posture, release baseline, runtime contract, or teaches a reusable incident lesson.

## Non-negotiable memory rules

- Runtime evidence beats stale documentation.
- Never guess tenant, financial, security or deployment facts.
- Never overwrite historical evidence; append corrections/decisions/releases.
- Keep HOT state concise; move history to COLD records.
- Record deployment drift when Git and production differ.
- CI guard is part of Definition of Done: `node scripts/ai-memory-guard.mjs`.
- A future agent must be able to answer: what is true, why, who owns it, what broke before, and what must not be changed blindly.
