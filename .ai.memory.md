## Hierarchy

## Required cycle
`READ -> AUDIT -> CLASSIFY -> REPAIR -> TEST -> VERIFY -> DOCUMENT -> GUARD -> PREFLIGHT -> CI -> GREEN`

Material work is incomplete until memory is considered and both local executable gates pass:
- `node scripts/ai-memory-guard.mjs`
- `node scripts/fitconnect-preflight.mjs`

Runtime beats stale docs. Never guess tenant, finance, security or deployment facts. Never silently rewrite history. Record drift. Future agents must be able to determine what is true, why, who owns it, what broke before, and what must not be changed blindly.
