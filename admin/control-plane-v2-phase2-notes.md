# FitConnect Admin Control Plane v2 — Phase 2

Scope is presentation-only. No auth, payment, database, tenant ownership, commerce queries, or data-view handlers are changed.

## Added
- Sidebar section hierarchy: Commerce, Platform, Catalogus, Relaties, Operations.
- Stronger active-navigation indicator.
- Sticky branded sidebar header.
- Contextual topbar treatment with connection health indicator.
- Workspace page header rail.
- Unified Vercel-style KPI rails.
- Sticky table headers and tighter workspace chrome.
- Responsive collapse behavior.

## Safety
Existing DOM hooks and business logic remain authoritative. This release adds no new runtime JavaScript.
